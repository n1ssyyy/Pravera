Routes

Five ways there. The fastest one that works carries the session.

Take a route away and watch the session fall to the next one. That is what Pravera does when a cable is pulled or a network drops, with the session still open.

  1. Cable

    Thunderbolt, USB4 or Ethernet between two machines. Beats any Wi-Fi.

    in use

  2. Subnet

    Both machines on the same network, found on their own.

    standing by

  3. Tailnet

    A WireGuard tunnel you already run. Direct, but wrapped.

    standing by

  4. Hole punch

    Straight through two NATs across the internet. No port forwarding.

    standing by

  5. Relay

    The last resort. Still end-to-end encrypted, measurably slower, and the meter says so.

    standing by

Features

One executable: the app, the host, the service, the installer and the updater.

  • Pixels that keep up

    Hardware H.264 when the GPU offers it, a software encoder when it doesn't. A lost packet costs one frame, not a frozen picture.

  • Input at your mouse's own rate

    Raw, uncoalesced input. Alt+F4, the Win key and the other system chords land on the far machine, not yours.

  • Everything on one connection

    System audio, a clipboard that arrives as you copy, and files that drag straight into a live session.

  • Several machines, one window

    Each session is a tab. So is each remote terminal.

  • Reach a machine nobody is sitting at

    A Windows service starts Pravera before anyone signs in. Ctrl+Alt+Del, UAC prompts and the lock screen all work.

  • No monitor, no problem

    A bundled virtual display driver gives a headless box a real 1920×1080 screen to host.

  • Let an AI agent drive

    One switch opens a loopback-only MCP tool bus: pointer, keyboard, clipboard, files. Off by default, every tool listed on screen.

  • Gaming mode

    Fullscreen on the far monitor, cursor locked to the window, system chords captured instead of stolen.

  • Encrypted end to end

    QUIC between your two machines. When a relay has to carry the session, it carries ciphertext.

  • Keeps itself current

    Checks for a release every few hours, verifies its SHA-256 and swaps itself in only when nobody is connected.
